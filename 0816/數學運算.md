## 中學數學運算

這部分對應國中數學程度,內容包含**加減乘除、餘數、次方、絕對值、四捨五入**等基礎運算。

### 1. 加減乘除(四則運算)

| 運算子 | 功能 | 範例 |
|:------:|:----:|:----:|
| `+` | 加法 | `3 + 2` → `5` |
| `-` | 減法 | `3 - 2` → `1` |
| `*` | 乘法 | `3 * 2` → `6` |
| `/` | 除法(結果是浮點數) | `3 / 2` → `1.5` |
| `//` | 整數除法(取商) | `3 // 2` → `1` |
| `%` | 取餘數(取餘) | `3 % 2` → `1` |
| `**` | 次方 | `2 ** 3` → `8` |

```python
# 中學範例:四則運算
a = 17
b = 5

print(a + b)      # 加法:22
print(a - b)      # 減法:12
print(a * b)      # 乘法:85
print(a / b)      # 除法:3.4(浮點數)
print(a // b)     # 整數除法:3(17 除以 5 的商)
print(a % b)      # 取餘數:2(17 除以 5 的餘數)
print(a ** 2)     # 次方:289(17 的平方)
```

**詳細說明:**
- `/` 與 `//` 的差別:`17 / 5 = 3.4`(完整小數),`17 // 5 = 3`(只取整數商)。
- `%` 常用於判斷「能否整除」,例如 `x % 2 == 0` 代表 `x` 是偶數。

### 2. 運算子優先順序

Python 遵循數學的先乘除後加減,括號 `()` 擁有最高優先權。

```python
# 中學範例:運算子優先順序
print(2 + 3 * 4)       # 14(先乘後加:3*4=12,再+2)
print((2 + 3) * 4)     # 20(括號優先:2+3=5,再*4)
print(2 + 3 * 4 - 1)   # 13(依優先順序依序計算)
print(2 ** 3 ** 2)     # 512(次方是右結合:先算 3**2=9,再算 2**9)
```

**詳細說明:**
- 次方運算子 `**` 是**右結合**(從右邊開始算),所以 `2 ** 3 ** 2 = 2 ** 9 = 512`。
- 善用括號可以讓程式碼更容易閱讀,也能避免誤判。

### 3. 絕對值與四捨五入

Python 內建的 `abs()` 計算絕對值,`round()` 做四捨五入。

```python
# 中學範例:絕對值與四捨五入
print(abs(-7))         # 7(絕對值)
print(abs(3.14))       # 3.14
print(round(3.14159))  # 3(四捨五入到整數)
print(round(3.14159, 2))  # 3.14(四捨五入到小數第 2 位)
```

**詳細說明:**
- `round(x, n)` 的第二個參數 `n` 代表要保留的小數位數。
- 若想「無條件進位」或「無條件捨去」,需要搭配其他函式庫,請見高中部分的 `math.ceil()` / `math.floor()`。

### 4. 判斷奇數偶數與質數(應用練習)

```python
# 中學範例:判斷奇數偶數
def 判斷奇偶(n):
    if n % 2 == 0:
        print(f"{n} 是偶數")
    else:
        print(f"{n} 是奇數")

判斷奇偶(10)   # 10 是偶數
判斷奇偶(7)    # 7 是奇數
```

```python
# 中學範例:判斷質數(只能被 1 和自己整除的大於 1 的整數)
def 判斷質數(n):
    if n <= 1:
        return False
    for i in range(2, int(n ** 0.5) + 1):   # 只需檢查到 n 的平方根
        if n % i == 0:
            return False
    return True

print(判斷質數(17))   # True(17 是質數)
print(判斷質數(20))   # False(20 不是質數)
```

**詳細說明:**
- 質數判斷只需要測試到 `n ** 0.5`(n 的平方根)即可,這是一種加速技巧。
- `range(2, 值)` 會產生從 2 到「值-1」的整數序列。

## 高中數學運算

這部分對應高中數學程度,需要匯入 Python 的 **`math` 模組**,內容包含**根號、三角函數、對數、指數、組合排列**等。

### 0. 先匯入 math 模組

```python
import math
```

> `math` 是 Python 內建模組,提供大量數學函數與常數(如圓周率 `π`、自然對數底 `e`)。

### 1. 根號、次方與對數

```python
import math

# 高中範例:根號與對數
print(math.sqrt(16))       # 4.0(根號 16)
print(math.pow(2, 10))     # 1024.0(2 的 10 次方)
print(2 ** 10)             # 1024(也可以用 ** 運算子)
print(math.log(100, 10))   # 2.0(以 10 為底的對數:log₁₀100 = 2)
print(math.log(math.e))    # 1.0(自然對數:ln e = 1)
```

**詳細說明:**
- `math.sqrt(x)` 回傳 `x` 的平方根。
- `math.log(x, 底)` 計算以指定底數的對數;`math.log(x)` 預設是自然對數(以 `e` 為底)。
- 高中常考的對數公式:$\log_a b = \frac{\ln b}{\ln a}$,可以用 `math.log(b, a)` 直接算。

### 2. 三角函數(弧度制)

Python 的三角函數使用**弧度(radian)**而非角度(degree)。

```python
import math

# 高中範例:三角函數
angle = math.radians(30)        # 把 30 度轉成弧度(π/6)
print(angle)                    # 0.5235987755982988(即 π/6)

print(math.sin(angle))          # 0.49999999999999994(sin 30° ≈ 0.5)
print(math.cos(angle))          # 0.8660254037844387(cos 30° ≈ √3/2)
print(math.tan(math.radians(45)))  # 0.9999999999999999(tan 45° ≈ 1)

# 反三角函數:已知 sin 值求角度
print(math.degrees(math.asin(0.5)))  # 30.000000000000004(arcsin 0.5 = 30°)
```

**詳細說明:**
- 一個完整的圓 = $2\pi$ 弧度 = 360 度,所以 1 度 = $\pi/180$ 弧度。
- `math.radians(x)` 把角度轉弧度;`math.degrees(x)` 把弧度轉角度。
- 因為浮點數誤差,`sin(30°)` 會得到 `0.49999999...` 而非精確的 `0.5`,這是正常的。

### 3. 圓周率與常見常數

```python
import math

# 高中範例:常用常數
print(math.pi)        # 3.141592653589793(圓周率 π)
print(math.e)         # 2.718281828459045(自然對數底 e)
print(math.tau)       # 6.283185307179586(2π)
print(math.inf)       # inf(無限大)
```

**詳細說明:**
- `math.tau` 就是 $2\pi$,有些公式用起來更直觀。
- 使用常數時**不要自己打一長串數字**,直接呼叫 `math.pi` 最精確。

### 4. 組合與排列(高中機率統計)

```python
import math

# 高中範例:C(5, 2)(從 5 個選 2 個的組合數)
print(math.comb(5, 2))      # 10

# 高中範例:P(5, 2)(從 5 個選 2 個並排列)
print(math.perm(5, 2))      # 20

# 階乘:5! = 5×4×3×2×1
print(math.factorial(5))    # 120
```

**詳細說明:**
- 組合 $C^n_k = \frac{n!}{k!(n-k)!}$,順序不重要。
- 排列 $P^n_k = \frac{n!}{(n-k)!}$,順序重要。
- `math.comb` 和 `math.perm` 是 Python 3.8 以後才有的函式,舊版本可用 `math.factorial` 自行計算。

### 5. 進位與捨去函式

```python
import math

# 高中範例:無條件進位 / 無條件捨去
print(math.ceil(3.2))      # 4(無條件進位)
print(math.floor(3.8))     # 3(無條件捨去)
print(math.trunc(3.99))    # 3(直接去掉小數,類似 int())
print(int(3.99))           # 3(另一種取整數方式)
```

**詳細說明:**
- `math.ceil(x)`:回傳大於等於 `x` 的最小整數(往正無限大進位)。
- `math.floor(x)`:回傳小於等於 `x` 的最大整數(往負無限大捨去)。

### 1. 微積分(符號微分與積分)

使用 `sympy` 可以得到**精確的數學符號解**。

```python
import sympy as sp

x = sp.symbols('x')          # 宣告符號變數 x

# 大學範例:求導數(微分)
f = x ** 3 + 2 * x ** 2 - x + 1
f_prime = sp.diff(f, x)      # 對 x 微分
print(f_prime)               # 3*x**2 + 4*x - 1

# 求第二次微分
f_double = sp.diff(f, x, 2)
print(f_double)              # 6*x + 4

# 大學範例:積分
g = x ** 2
print(sp.integrate(g, x))    # x**3/3(不定積分)

# 定積分:從 0 積到 3
print(sp.integrate(g, (x, 0, 3)))   # 9
```

**詳細說明:**
- `sp.diff(函數, 變數, 次數)`:第一個參數是函數,第二個是要對哪個變數微分,第三個(可選)是微分次數。
- `sp.integrate(函數, (變數, 下界, 上界))`:加上積分區間就是定積分。
- `sympy` 用符號計算,所以答案是「精確」的,例如 `x**3/3`,不會有小數誤差。

### 2. 極限

```python
import sympy as sp

x = sp.symbols('x')

# 大學範例:求極限 lim(x→0) (sin x)/x
f = sp.sin(x) / x
print(sp.limit(f, x, 0))     # 1(高中背的公式,用 Python 驗證!)

# lim(x→∞) (1 + 1/x)^x = e
g = (1 + 1 / x) ** x
print(sp.limit(g, x, sp.oo))  # E(自然對數底,等於 e)
```

**詳細說明:**
- `sp.limit(函數, 變數, 趨近值)` 計算極限,`sp.oo` 代表無限大。
- 第一個範例是微積分重要極限 $\lim_{x\to 0}\frac{\sin x}{x}=1$,可直接驗證。

### 3. 解方程式與線性代數

```python
import sympy as sp

x, y = sp.symbols('x y')

# 大學範例:解一元二次方程式 x² - 5x + 6 = 0
eq = sp.Eq(x ** 2 - 5 * x + 6, 0)
print(sp.solve(eq, x))       # [2, 3]

# 大學範例:解聯立方程式
eq1 = sp.Eq(x + y, 10)
eq2 = sp.Eq(x - y, 2)
print(sp.solve([eq1, eq2], [x, y]))    # {x: 6, y: 4}

# 大學範例:矩陣運算
A = sp.Matrix([[1, 2], [3, 4]])
B = sp.Matrix([[5, 6], [7, 8]])

print(A + B)        # 矩陣相加
print(A * B)        # 矩陣相乘
print(A ** 2)       # 矩陣平方
print(A.det())      # 行列式值:-2
print(A.inv())      # 反矩陣
print(A.T)          # 轉置矩陣
```

**詳細說明:**
- `sp.Eq(左式, 右式)` 用來建立方程式,再用 `sp.solve` 求解。
- `sp.Matrix` 提供完整的矩陣功能,大學線性代數常用的運算都有了。

### 4. 數值運算(NumPy 陣列)

`numpy` 適合大量資料的數值計算,`np.array` 可以進行向量化的批次運算。

```python
import numpy as np

# 大學範例:建立陣列
a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

print(a + b)        # [11 22 33 44](逐元素相加)
print(a * b)        # [10 40 90 160](逐元素相乘)
print(a ** 2)       # [1 4 9 16](每個元素平方)

# 建立等差數列:0 到 1,共 5 個點
print(np.linspace(0, 1, 5))   # [0.   0.25 0.5  0.75 1.  ]

# 建立 3×3 全 0 矩陣與單位矩陣
print(np.zeros((3, 3)))
print(np.eye(3))
```

**詳細說明:**
- NumPy 的陣列運算會「逐元素」進行,一次處理整個陣列,速度比 Python 迴圈快非常多。
- `np.linspace(起點, 終點, 個數)` 產生等間距的數字,繪圖時很常用。

### 5. 統計運算

```python
import statistics

# 大學範例:統計學描述性統計
data = [12, 15, 18, 20, 22, 25, 30, 35, 40, 60]

print(statistics.mean(data))       # 27.7(平均數)
print(statistics.median(data))     # 23.5(中位數)
print(statistics.mode([1, 2, 2, 3]))  # 2(眾數)
print(statistics.stdev(data))      # 14.03(樣本標準差)
print(statistics.variance(data))   # 196.90(樣本變異數)
```

```python
# 使用 numpy 計算(結果較常用)
import numpy as np

data = np.array([12, 15, 18, 20, 22, 25, 30, 35, 40, 60])

print(np.mean(data))       # 27.7(平均數)
print(np.std(data))        # 13.30(母體標準差)
print(np.var(data))        # 176.81(母體變異數)
print(np.min(data), np.max(data))   # 12 60(最小與最大值)
print(np.percentile(data, 50))      # 23.5(第 50 百分位數 = 中位數)
```

**詳細說明:**
- `statistics.stdev` 是**樣本標準差**(除以 n-1),`np.std` 是**母體標準差**(除以 n),兩者公式不同。
- 數列為偶數個時,中位數是中間兩個數的平均。

### 6. 繪製函數圖形

用 `matplotlib` 把函數畫出來,是理解數學的好工具。

```python
import numpy as np
import matplotlib.pyplot as plt

# 大學範例:畫出 y = x² 與 y = x³ 的圖形
x = np.linspace(-3, 3, 100)    # 在 -3 到 3 之間取 100 個點
y1 = x ** 2
y2 = x ** 3

plt.plot(x, y1, label="y = x²")
plt.plot(x, y2, label="y = x³")
plt.xlabel("x")
plt.ylabel("y")
plt.title("函數圖形")
plt.legend()      # 顯示圖例
plt.grid()        # 顯示格線
plt.show()
```

**詳細說明:**
- `np.linspace(-3, 3, 100)` 產生 100 個均勻分布的 x 座標,再算出對應的 y。
- 在 Jupyter Notebook 中會直接顯示圖片;用 `.py` 檔案執行則會跳出視窗。

### 7. 解微分方程式

```python
import sympy as sp

x = sp.symbols('x')
f = sp.Function('f')

# 大學範例:解微分方程式 f'(x) = f(x),並代入初始條件 f(0) = 1
eq = sp.Eq(f(x).diff(x), f(x))
sol = sp.dsolve(eq, f(x), ics={f(0): 1})
print(sol)    # Eq(f(x), exp(x))  → 解為 f(x) = eˣ
```

**詳細說明:**
- `f(x).diff(x)` 代表 `f'(x)`。
- `sp.dsolve(方程式, 未知函數, ics=初始條件)` 解常微分方程式,`ics` 給定初始值條件後可得到特定解。

## 重點整理

1. **基本運算**直接用 Python 內建,不需要匯入任何函式庫。
2. 遇到**根號、三角函數、對數、組合排列**時,匯入 `math`。
3. 大學階段常需要**符號精確解**,使用 `sympy`;處理**大量數值資料**時使用 `numpy`。
4. `sympy` 給出**精確答案**(如 `x**3/3`),`numpy`/`math` 給出**近似值**(如 `0.333...`),依需求選擇。
5. 練習方式:**動手改數字、動手改公式**,觀察結果變化,是學數學最好的方式。
